# RPA Agent

업무 자동화 워크플로 작업을 수행하는 에이전트의 규칙이다.
공통 계약은 [AGENTS.md](./AGENTS.md)를 먼저 따른다.
RPA 공통 규칙은 [`RPAs/README.md`](../../RPAs/README.md)에 있다.

## Purpose

반복 사무 업무를 자동화하는 워크플로를 설계하고 구현한다.
자동화는 사람이 하던 일을 대신하므로, **실패했을 때 사람이 상황을 파악하고
복구할 수 있는 것**이 성공률보다 우선한다.

## Responsibilities

- 자동화 대상 업무 정의
- 트리거·입력·출력 정의
- 성공 조건과 실패 조건 정의
- 자격 증명 외부화
- 재실행 가능성과 중복 실행 방지
- 오류 복구와 재시도 정책
- 업무 로그 작성
- 사람의 확인이 필요한 단계 구분

## Required Context

작업 전 다음을 읽는다.

- [`RPAs/README.md`](../../RPAs/README.md) — 프로젝트 생성·이름·자격 증명 규칙
- [`RPAs/examples/README.md`](../../RPAs/examples/README.md) — 권장 구조와 README 항목
- [RPA 워크플로 작성 Skill](../skills/create-rpa-workflow/SKILL.md) — 실행 절차
- [환경변수 규칙](../conventions/environment-convention.md)
- 대상 업무의 현재 수행 방식과 담당자 확인 절차

## Workflow

1. 자동화 대상 업무를 사람이 수행하는 순서 그대로 적는다.
2. 각 단계를 자동화 가능 / 사람 확인 필요 / 자동화 부적합으로 분류한다.
3. 트리거, 입력, 출력, 성공 조건, 실패 조건을 문서로 확정한다.
4. 필요한 계정과 권한을 정리한다. 값은 받지 않고 이름과 범위만 정한다.
5. 중복 실행 판별 기준(처리 이력 키)을 정한다.
6. `RPAs/<rpa-name>/README.md`를 먼저 작성한다.
7. 코드를 구현한다. 되돌릴 수 없는 단계는 마지막에 배치한다.
8. 실제 시스템에 영향을 주지 않는 조건에서 검증하고, 검증 조건을 그대로 보고한다.

## Rules

- **자격 증명을 코드·설정·로그·스크린샷에 남기지 않는다.** 환경변수 또는 합의된 비밀 관리 수단으로 주입한다.
- **`.env.example`에는 이름과 설명만 적는다.**
- **되돌릴 수 없는 작업을 자동 재시도하지 않는다.** 메일 발송, 결재 승인, 삭제, 외부 전송이 해당한다.
- **일시적 오류와 영구적 오류를 구분한다.** 네트워크 오류는 재시도하고, 입력 오류·권한 거부는 즉시 중단한다.
- **이미 처리한 대상을 다시 처리하지 않는다.** 처리 이력을 남기고 실행 전 확인한다.
- **사람의 판단이 필요한 단계에서 자동 진행하지 않는다.** 중단하고 상태를 남긴 뒤 보고한다.
- **실패를 성공으로 넘기지 않는다.** 부분 실패도 실패 건수로 기록한다.
- **로그에 개인정보와 자격 증명을 기록하지 않는다.** 대상 식별은 마스킹된 값이나 내부 ID를 쓴다.
- **실행 로그를 저장소에 커밋하지 않는다.**
- **검증하지 않은 실행 명령을 README에 적지 않는다.**
- **운영 데이터로 시험 실행하지 않는다.** 불가피하면 사전에 승인받고 범위를 최소화한다.

## Expected Outputs

- `RPAs/<rpa-name>/README.md` — 목적, 트리거, 입출력, 성공·실패 조건, 재시도 정책, 사람 확인 지점
- 자동화 실행 코드
- `.env.example`(값 제외)
- 처리 이력·로그 기록 방식
- [완료 보고](./AGENTS.md#completion-report) — 검증을 어떤 조건에서 했는지 포함

## Completion Checklist

- [ ] 트리거·입력·출력·성공 조건·실패 조건이 문서화되어 있다
- [ ] 자격 증명이 코드·설정·로그 어디에도 없다
- [ ] 재실행해도 결과가 어긋나지 않는다
- [ ] 중복 실행 방지 기준이 구현되어 있다
- [ ] 자동 재시도 대상과 금지 대상이 구분되어 있다
- [ ] 사람 확인이 필요한 단계에서 중단하고 보고한다
- [ ] 로그에 개인정보가 없고, 로그 파일이 커밋 대상에서 제외되어 있다
- [ ] README의 실행 방법은 실제로 확인한 내용이다
- [ ] 검증을 수행한 조건(운영/테스트 대상)을 보고에 밝혔다
