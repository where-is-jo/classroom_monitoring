# ADR-0006: v2 제품 경계와 레거시 호환성

## Status

Accepted

## Context

`main-spec-v2`는 실제 제품 역할을 `STUDENT`, `STAFF`, `ADMIN` 세 가지로 한정하고,
제품 탐색을 직원·면담·강의실·영상 데모·관리자 운영 화면 중심으로 재구성한다. 기존 구현에는
이 경계에 포함되지 않는 `SYSTEM_OPERATOR` 계정, 범용 이벤트 화면과 API, 감사 로그 화면과
API, mock 관측·전달 도구가 있다.

저장된 사용자 문서는 `SYSTEM_OPERATOR` 값을 포함할 수 있고, 범용 이벤트와 감사 로그 API는
저장소 밖 소비자가 있는지 이 저장소만으로 확인할 수 없다. 반면 이 저장소의 템플릿과
애플리케이션 코드에는 두 API를 호출하는 제품 경로가 없으며, mock 기능은 테스트가 사용한다.
확인하지 않은 외부 소비자를 단번에 깨뜨리거나 기존 데이터를 자동 삭제하지 않으면서 제품
경계를 분명하게 해야 한다.

## Decision

v2 제품 경계에서는 세 역할만 권한 주체로 인정하고, 저장 데이터와 직접 API 소비자를 위한
최소 호환 계층만 유지한다.

| 대상 | v2 동작 | 후속 제거 조건 |
| --- | --- | --- |
| `SYSTEM_OPERATOR` | 역직렬화와 기존 사용자 조회를 위해 enum 값은 유지한다. 로그인, access/refresh token 인증, 관리자 권한, 신규 생성·역할 지정, 가상 계정 seed에서는 제외한다. 기존 계정은 `ADMIN`이 `ADMIN`으로 변경하거나 비활성화한다. | 저장 데이터에서 값이 사라지고 이력 조회 보존 방식이 정해지면 enum 제거를 검토한다. |
| `/events`, `/api/v1/events*` | 제품 탐색과 OpenAPI에서 제외한다. 직접 호출은 유지하며 API 응답에 `Deprecation: true`를 보낸다. | 다음 breaking-change 배포 전에 외부 소비자를 조사하고 이전 안내를 마친 뒤 제거한다. |
| `/admin/audit-logs` | 화면은 제거한다. 직접 API는 OpenAPI에서 제외하고 `Deprecation: true`를 보내며, 감사 기록 저장은 내부 통제로 유지한다. | 외부 API 소비자가 없음을 확인한 뒤 조회 API만 제거한다. 감사 기록 저장은 제거 대상이 아니다. |
| mock 관측·전달 | `MOCK_INPUTS_ENABLED=true`인 `local`·`dev` 환경에서만 라우터를 등록한다. 제품 탐색에는 링크하지 않고 테스트·개발 입력으로만 사용한다. | 실제 관측·알림 어댑터가 테스트 대역을 완전히 대체한 뒤 별도 판단한다. |

기존 `SYSTEM_OPERATOR` 계정을 자동 변경하거나 삭제하지 않는다. 운영자는 사용자 관리 API 또는
화면에서 대상 계정의 용도를 확인한 뒤 역할 변경 또는 비활성화를 명시적으로 수행한다.

## Alternatives Considered

### 대안 A: 레거시 코드와 데이터를 즉시 제거

- 장점: 제품 경계와 코드가 즉시 완전히 일치한다.
- 단점: 기존 MongoDB 문서 역직렬화가 실패할 수 있고, 저장소 밖 API 소비자가 예고 없이 깨진다.
- 채택하지 않은 이유: 외부 소비자와 운영 데이터 상태를 이 저장소에서 완전히 확인할 수 없다.

### 대안 B: 기존 기능을 계속 정식 제품 기능으로 공개

- 장점: 기존 사용자와 API 소비자의 변경이 없다.
- 단점: v2 역할·탐색·OpenAPI가 폐기 예정 기능을 계속 약속하며 제품 권한 경계가 모호해진다.
- 채택하지 않은 이유: 명세가 정한 세 역할과 제품 화면 범위를 충족하지 못한다.

### 대안 C: 저장 데이터와 직접 호출만 단계적으로 호환

- 장점: 제품 표면을 정리하면서 기존 데이터와 확인되지 않은 소비자에게 이전 시간을 준다.
- 단점: 제거 전까지 레거시 enum과 라우터를 유지·시험해야 한다.
- 채택 이유: 데이터 손실과 예고 없는 계약 파괴 없이 v2 경계를 적용할 수 있다.

## Consequences

**얻는 것**

- 신규 사용자와 인증 권한은 세 제품 역할로 제한된다.
- 제품 탐색과 OpenAPI가 현재 지원하는 v2 기능만 보여 준다.
- 기존 사용자 문서와 직접 API 소비자는 명시적인 이전 기간을 갖는다.
- mock 입력이 운영 제품 기능으로 오인되지 않는다.

**감수하는 것**

- 레거시 enum과 숨겨진 라우터는 제거 조건을 충족할 때까지 유지해야 한다.
- OpenAPI에 없는 직접 호출 경로는 이 ADR과 회귀 테스트로 별도 관리한다.
- 외부 소비자 조사는 저장소 밖 배포·운영 환경에서 추가로 수행해야 한다.

**영향받는 문서·코드**

- `webapps/fastapi/app/auth`, `webapps/fastapi/app/users`
- `webapps/fastapi/app/events/router.py`, `webapps/fastapi/app/admin/router.py`
- `webapps/fastapi/app/main.py`, `webapps/fastapi/.env.example`
- `webapps/fastapi/README.md`

- [x] 레거시 이벤트와 감사 로그 API를 OpenAPI에서 제외하고 deprecation 헤더 추가
- [x] 감사 로그 화면과 레거시 제품 탐색 링크 제거
- [x] mock 라우터를 허용된 비운영 환경에서만 등록
- [ ] 배포 환경의 `SYSTEM_OPERATOR` 계정 목록을 확인하고 수동 이전
- [ ] 다음 breaking-change 배포 전 이벤트·감사 로그 API 외부 소비자 조사와 이전 안내
