# 배포

**목적**: 배포 방식이 정해지기 전까지 무엇을 결정해야 하는지, 배포할 때 무엇을
지켜야 하는지 정리한다.
**대상 독자**: 배포 방식을 정하거나 실제로 배포하게 될 팀원.

> **배포 절차는 아직 없다.** 배포 대상 환경도, 방식도 정해지지 않았다.
> 이 문서는 절차서가 아니라, 절차를 만들 때 답해야 할 질문 목록이다.
> 확정되는 대로 이 문서를 절차서로 바꾼다.

## 결정해야 할 것

| 항목 | 상태 | 고려 사항 |
| --- | --- | --- |
| 배포 대상 환경 | 결정 필요 | 사내 서버 / 클라우드 / 온프레미스 장비 |
| 컨테이너 사용 여부 | 결정 필요 | deeplearning의 GPU 접근, Jetson 실행 가능성 |
| 서비스 오케스트레이션 | 결정 필요 | 최상위에 인프라 파일을 두지 않는 제약 |
| 이미지·아티팩트 보관 위치 | 결정 필요 | |
| 배포 자동화 | 결정 필요 | 수동 배포로 시작할지 |
| 비밀값 주입 방법 | 결정 필요 | [환경변수 규칙](../conventions/environment-convention.md) 참고 |
| 모델 가중치 전달 방법 | 결정 필요 | 이미지 포함 / 볼륨 마운트 / 객체 저장소 |
| 롤백 방법 | 결정 필요 | 되돌릴 수 없는 변경을 어떻게 다룰지 |
| 로그 수집 위치 | 결정 필요 | |

결정하면 [ADR](../architecture/decisions/README.md)로 남기고
[아키텍처 개요의 미결정 항목](../architecture/overview.md#미결정-항목)과 이 표를 함께 갱신한다.

## 서비스별로 미리 고려할 점

배포 방식과 무관하게 각 서비스가 가진 제약이다.

- **deeplearning** — GPU 접근과 모델 가중치 전달이 필요하다. 가중치는 저장소에 없으므로
  배포 시점에 어떻게 전달할지가 배포 방식 선택에 영향을 준다.
- **worker** — 카메라·Jetson과 네트워크로 닿아야 한다. 배치 위치가 네트워크
  구성에 묶인다.
- **fastapi** — 외부 진입점이므로 접근 제어와 인증서가 필요하다.
- **fastapi** — 외부 진입점이므로 접근 제어와 인증서가 필요하다. 정적 자산 서빙 방식도 함께 정한다.
- **monitoring** — 다른 서비스의 지표 노출 지점에 닿아야 한다.
- **RPA** — 상시 실행이 아니다. 일정 실행 수단이 별도로 필요하다.

## 배포 전 확인

절차가 정해진 뒤에도 아래는 공통으로 지킨다.

- [ ] 비밀값이 이미지·설정 파일·로그에 포함되지 않는다
- [ ] `.env.example`이 최신이고, 새 필수 환경변수가 대상 환경에 주입되어 있다
- [ ] 필수 환경변수 검증이 기동 시 동작한다
- [ ] 테스트가 통과했다
- [ ] 되돌릴 수 없는 변경(스키마 삭제, 데이터 이관)이 있는지 확인했다
- [ ] 롤백 방법을 확인했다
- [ ] API 계약을 깨는 변경이 있다면 소비자가 준비되어 있다
- [ ] 영상·개인정보의 저장 범위가 합의된 범위를 넘지 않는다

## 배포 중 지킬 것

- **운영에서만 실행되는 코드 경로를 만들지 않는다.**
  환경에 따라 값만 다르게 하고 분기는 만들지 않는다.
- **운영 데이터를 직접 수정해 상태를 맞추지 않는다.**
- 문제가 생기면 원인을 찾기 전에 먼저 되돌린다.
- 배포 후 지표와 로그로 정상 동작을 확인한다. 확인하지 않은 배포는 끝난 것이 아니다.
