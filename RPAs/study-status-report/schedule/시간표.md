# 시간표

study-status-report RPA가 읽는 시간표 문서다. 형식은
`RPAs/study-status-report/templates/schedule-sample.md`를 따른다.

**이 파일은 저장소가 관리한다.** 개인 노트가 아니라 운영 설정이다 — RPA가 읽지 못하면
Slack에 알린 뒤 기록을 중단하므로, 저장소에 없으면 다른 호스트에 배포할 때 그대로
실패한다. 시간이 바뀌면 여기를 고쳐 커밋한다. 재기동도 워크플로 수정도 필요 없다.

**구간 이름에 `자습`·`교시`가 들어간 줄만 기록 대상이다.** 쉬는시간·점심은
자동으로 제외된다.

50분 수업 + 10분 휴식. 오전 4교시, 점심 13:10~14:10, 오후 4교시, 18:00 종료.

| 시간 | 구간 |
| --- | --- |
| **09:20 ~ 10:10** | 1교시 |
| **10:10 ~ 10:20** | 쉬는시간 |
| **10:20 ~ 11:10** | 2교시 |
| **11:10 ~ 11:20** | 쉬는시간 |
| **11:20 ~ 12:10** | 3교시 |
| **12:10 ~ 12:20** | 쉬는시간 |
| **12:20 ~ 13:10** | 4교시 |
| **13:10 ~ 14:10** | 점심 |
| **14:10 ~ 15:00** | 5교시 |
| **15:00 ~ 15:10** | 쉬는시간 |
| **15:10 ~ 16:00** | 6교시 |
| **16:00 ~ 16:10** | 쉬는시간 |
| **16:10 ~ 17:00** | 7교시 |
| **17:00 ~ 17:10** | 쉬는시간 |
| **17:10 ~ 18:00** | 8교시 |
