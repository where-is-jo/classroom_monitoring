# 시간표 (예시)

이 파일은 **형식을 보여주는 예시**다. 실제 시간표는 `../schedule/시간표.md`에 두며,
그 파일은 운영 설정이라 저장소가 함께 관리한다.

## 워크플로가 읽는 형식

`Parse Schedule` 노드가 아래 정규식으로 줄을 찾는다.

```text
**시작시각 ~ 종료시각** | 구간 이름
```

- 시각은 반드시 `HH:MM` **두 자리**다. `8:00`은 인식되지 않는다.
- 시각 양쪽의 `**`(굵게)와 가운데 `|`가 있어야 한다.
- **구간 이름에 `자습`·`교시`·`study`·`period` 중 하나가 들어간 줄만 기록 대상이다.**
  등원·점심·저녁·하원은 이 조건에 걸리지 않아 자동으로 제외된다.
- 조건에 맞는 줄이 하나도 없으면 파싱 실패로 보고, Slack에 알린 뒤 중단한다.

## 예시

표로 써도 되고, 표 없이 한 줄씩 써도 된다. 둘 다 인식한다.

| 시간 | 구간 |
| --- | --- |
| **07:40 ~ 08:00** | 등원 |
| **08:00 ~ 08:40** | 아침 자습 |
| **08:40 ~ 10:10** | 1교시 |
| **10:20 ~ 11:50** | 2교시 |
| **11:50 ~ 13:00** | 점심 |
| **13:00 ~ 14:30** | 3교시 |
| **14:40 ~ 16:10** | 4교시 |
| **16:20 ~ 17:50** | 5교시 |
| **17:50 ~ 19:00** | 저녁 |
| **19:00 ~ 20:30** | 야간 1교시 |
| **20:40 ~ 22:00** | 야간 2교시 |
| **22:00 ~ 22:20** | 하원 |

위 예시에서 기록 대상은 자습·교시가 들어간 8개 구간이고, 등원·점심·저녁·하원
4개는 제외된다.
