# RPAs / shared / documentation

여러 RPA 프로젝트가 공통으로 참고하는 **문서**를 두는 공간이다.

## 여기에 두는 것

- 여러 자동화가 함께 접근하는 사내 시스템의 사용 절차 정리
- 공통 예외 상황과 대응 방법(예: 대상 시스템 점검 시간)
- 자동화 대상 업무의 담당자·확인 절차 정리
- 자동화 운영 시 반복되는 주의사항

## 여기에 두지 않는 것

- **실행 코드와 공통 라이브러리.** 공통 코드가 필요하다는 판단이 서기 전까지
  이 디렉터리에 코드를 만들지 않는다. 실제로 두 개 이상의 RPA가 같은 코드를
  필요로 하는 상황이 확인되면, 그때 위치와 형태를 팀이 결정한다.
- 특정 RPA 하나에만 해당하는 설명. 해당 프로젝트 README에 둔다.
- 자격 증명, 실제 개인정보가 포함된 샘플

## 작성 규칙

- 문서 이름은 소문자와 하이픈을 사용한다.
- 문서 첫머리에 목적과 대상 독자를 한 줄로 적는다.
- 각 RPA 프로젝트 README에서 이 문서로 상대 경로 링크를 건다.
- 같은 내용을 여러 프로젝트 README에 복사하지 말고 이곳으로 모은다.
