# RPAs / shared / assets

여러 RPA 프로젝트가 공통으로 사용하는 **자산 파일**을 두는 공간이다.

## 여기에 두는 것

- 보고서·메일 양식 템플릿
- 공통으로 쓰는 이미지, 아이콘 등 참조 자산
- 자동화 대상 화면의 기준 캡처(요소 식별용, 개인정보 제거 후)
- 공통 입력 양식 예시 파일

## 여기에 두지 않는 것

- 실행 코드
- 자격 증명이 담긴 설정 파일
- 실제 업무 데이터, 개인정보가 포함된 파일
- 특정 RPA 하나만 쓰는 자산(해당 프로젝트 디렉터리에 둔다)
- 자동으로 생성되는 산출물(실행 결과 파일 등)

## 작성 규칙

- 파일 이름은 소문자와 하이픈을 사용하고, 용도를 알 수 있게 짓는다.
- 자산이 늘어나면 용도별 하위 디렉터리로 나누고, 각 디렉터리에 README를 둔다.
- 대용량 바이너리는 커밋 전 필요성을 확인한다.
- 화면 캡처는 등록 전 개인정보와 사내 비공개 정보가 없는지 확인한다.
