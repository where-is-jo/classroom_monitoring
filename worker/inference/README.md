# inference worker

`stream` worker가 고른 프레임에서 사람과 수화기를 탐지하는 워커다.

> 현재 상태: 구현 전. 이 문서는 구현 시 지킬 책임 범위를 정의한다.

## 서비스 목적

프레임을 받아 "무엇이 어디에 있는가"를 좌표와 신뢰도로 돌려준다.
이 워커가 없으면 영상은 저장만 될 뿐 아무 정보도 만들어내지 못한다.

## 책임

- 모델 로딩 — 프로세스 시작 시 1회. 프레임마다 다시 불러오지 않는다
- 프레임 전처리와 추론 실행
- 탐지 결과 스키마 정의와 유지
- CPU/GPU 실행 경로 유지
- 신뢰도 임계값 등 추론 파라미터의 설정화
- 추론 지연·처리량 지표 노출

## 포함하지 않아야 할 기능

- 스트림 연결 관리와 재연결 → [`stream`](../stream/README.md) 책임
- 탐지 결과의 업무 해석 → [`state`](../state/README.md) 또는 `fastapi` 책임.
  **"사람 1명, 신뢰도 0.87"까지가 이 워커의 출력이다.** "근무중"으로 바꾸지 않는다
- 탐지 결과의 영속 저장 → `fastapi` 책임
- 영상 저장 → [`recorder`](../recorder/README.md) 책임

## 예상 기술

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 언어 | Python | |
| 모델 | 후보: YOLO 계열 | 종류와 버전 `결정 필요` |
| 실행 장치 | `결정 필요` | CPU 경로를 반드시 함께 유지한다 |
| 프레임 수신 방식 | `결정 필요` | 동기 호출 / 공유 저장소 / 큐 |
| 결과 전달 방식 | `결정 필요` | 동기 응답 / 큐 |

모델 가중치 파일은 저장소에 커밋하지 않는다. 경로와 버전은 환경변수로 주입한다.

## 다른 서비스와의 관계

- **`stream`**: 프레임 공급자다. 전달 방식이 `결정 필요`이므로 임의로 구현하지 않는다.
- **`state`**: 탐지 결과 소비자다.
- **`deeplearning`**: 모델 코드와 가중치의 출처다. 경계는 `결정 필요`.
- **브라우저**: 직접 호출하지 않는다.

## 환경변수

> 구현 시 `.env.example`과 함께 채운다. 이름과 용도만 적고 실제 값은 넣지 않는다.

| 이름 | 용도 | 비고 |
| --- | --- | --- |
| `MODEL_PATH` | 모델 가중치 경로 | 기본값을 주지 않는다 |
| `MODEL_VERSION` | 모델 버전 | |
| `INFERENCE_DEVICE` | 실행 장치 | `cpu` / `cuda` |
| `INFERENCE_CONFIDENCE_THRESHOLD` | 탐지 신뢰도 임계값 | |

## 테스트 전략

- 전처리와 결과 변환은 모델 없이 단위 테스트한다.
- 실제 모델 가중치가 필요한 테스트는 분리해 기본 실행에 넣지 않는다.
- 측정하지 않은 성능 수치를 문서에 적지 않는다.
